# 📊 Retail Store Business Intelligence Dashboard

An interactive Business Intelligence Dashboard developed using **Python, Streamlit, Pandas, and Plotly** to analyze retail sales data and generate meaningful business insights.

This dashboard helps visualize sales performance, customer ratings, inventory status, product performance, revenue, and profit through interactive charts and KPIs.

---

## 🚀 Features

- 📈 Interactive KPI Dashboard
- 💰 Revenue & Profit Analysis
- 📊 Monthly Sales Trend Analysis
- 🥧 Best Selling Products Analysis
- 📂 Best Category Insights
- 📦 Inventory Status Monitoring
- ⭐ Customer Feedback Analysis
- 🎯 Interactive Filters (Product, Category & Month)
- 📥 Download Report Feature
- 📱 Responsive Dashboard Layout

## ▶️ How to Run

Clone the repository

```bash
git clone https://github.com/reshmashaik292007-hash/Retail-Store-Business-Intelligence-Dashboard.git
```

Move into the project folder

```bash
cd Retail-Store-Business-Intelligence-Dashboard
```

Install the required packages

```bash
pip install -r requirements.txt
```

Run the application

```bash
streamlit run app.py
```
